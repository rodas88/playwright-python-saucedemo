# SauceDemo QA Automation with Playwright

A hands-on QA automation project built with Python, Playwright, and Pytest using the SauceDemo web application.

This repository documents my practical learning journey in QA Automation, progressing from basic browser interactions to structured and reusable automated tests.

## Current Automated Scenario

The current automation includes:

1. Opening SauceDemo.
2. Entering valid user credentials.
3. Performing login.
4. Validating successful navigation to the inventory page.
5. Validating inventory elements.
6. Capturing screenshots as test evidence.

## Run the Tests

```bash
python -m pytest automation/saucedemo_modulo7_fixtures.py -s
```
